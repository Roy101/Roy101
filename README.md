## 🔬 What I'm working on

- 🧬 **Code clones in the LLM era**: benchmarks and evaluations of clone detectors on AI-generated code
- 🔀 **Model merging for software engineering**: one cross-domain model from specialist checkpoints, without retraining
- 🌱 **Efficient, sustainable code models**: compressing code transformers to cut memory and CO2 while keeping accuracy
- 🛠️ **Just-in-time clone refactoring**: helping developers refactor clones as they write code
